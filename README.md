# Makas AI — makasai.net

Makas AI tanıtım sitesi: düz HTML, CSS ve JavaScript; derleme gerekmez.

- `index.html` — ana sayfa (İngilizce ve Türkçe)
- `signup.html`, `login.html`, `reset.html`, `account.html` — hesap sayfaları
- `config.js` — lisans sunucusu adresi, fiyatlar ve indirme bağlantıları

Yayın: GitHub Pages, `main` dalı, kök klasör. Alan adı `CNAME` dosyasındadır.
